# 05 — Skills

Source: Corebook pp. 78–82. Data: `skills.json` (24 Skills).

## For the app

- Each Skill has a suggested Attribute (`attribute`). The GM may allow other pairings.
- Training 0–3 and Focus 0–3 are stored separately. Each level of Training adds one die to the Test pool. Each level of Focus adds +1 to a single die.
- Costs: see `11-advancement/advancement-costs.json`.
- Core Skill: each Archetype sets a Core Skill (start with Training 1 and Focus 1 in it), in `04-archetypes/`.
- Derived: Natural Awareness and Initiative use Awareness and Reflexes Training (`skills.json`, `derived`).

## Files

- `skills.json`: the 24 Skills.
